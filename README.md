# Rabbit Hole – Tägliche Inhalte

Die Wissenstexte für die iPhone-App **Rabbit Hole**, ein Tag pro Datei.

- `days/index.json` – alle verfügbaren Tage
- `days/JJJJ-MM-TT.json` – drei Einstiegsthemen mit je drei Ebenen (39 Texte)

Die Texte werden jede Nacht automatisch mit Claude erzeugt und gegen­geprüft (Anknüpfung an den vorherigen Text, Faktencheck mit Websuche). KI-generiert – Fehler bitte melden.
